# Phase 3: differentiation and growth
Read COMMON_RULES.md first. Start only after Phase 2 is merged. Branch `phase3-growth`. Spec: `docs/NEXT_BUILD_BRIEF.md` items 11 to 15.

## Tasks
1. **Strategy comparison (Premium).** `/app/strategies/compare`: choose 2 to 4 strategies; side-by-side metrics (trades, win rate, expectancy, profit factor, average R, max drawdown) and overlaid equity curves in one chart. Reuse `summarize`; same filters as Phase 2. Server-side Premium gate, and a clear message for Standard and Free. Small-sample warning per strategy.
2. **Manual backtest log (Premium).** Hypothetical trades must **never** mix with real statistics. Prefer a separate table `tradenotes.backtest_trades` (RLS, isolation checks, `EXPECTED_TABLES` updated) over a flag on `trades`. Same entry form fields, same metrics page, screenshots allowed (reuse the storage design, separate path prefix inside the same bucket, counted in the user's quota), a permanent "HYPOTHETICAL: not real trades" label on every screen and export. Do not build bar replay; write the licensing memo in Phase 4.
3. **Public demo at `/demo`.** Static seeded data in code (no database, no account, no tracking beyond existing analytics). Read-only copies of dashboard, analytics and one trade page built from the same components, a "SAMPLE DATA" banner everywhere, links from the landing page and pricing. Add `/demo` routes to the `middleware` matcher only if needed (middleware must not import `pg`), to the CI smoke test list in `.github/workflows/ci.yml`, to the sitemap, and make sure `robots` and canonical tags follow `docs/SEO.md`.
4. **Shareable report links.** New table `tradenotes.share_links` (user_id, token stored as a hash, scope: which report and filters, expires_at, revoked_at, created_at; RLS; isolation checks). Owner creates and revokes links in Settings; the public page `/r/<token>` is read-only, shows aggregate metrics and the equity curve only, **no trade notes, no account names, no emails, no screenshots**, `noindex`, short cache, and shows "Generated from the owner's journal, not financial advice". Revoked or expired links return 404. Cross-user test: B cannot list, revoke or read A's links. Privacy Policy update. Run `security-review` on this task.
5. **Mobile quick-log.** `/app/quick`: six fields (instrument, side, size, entry, exit or open, stop) with large touch targets, defaults from the last trade, saves in one tap, links to "add details later". PWA install hints: web manifest and icons, "Add to home screen" tip; no service worker unless it is necessary and tested. 390px e2e.
6. **Plan copy** as in Phase 2 task 7, and QA as in COMMON_RULES.md.

## Done means
Comparison and backtest log gated to Premium; `/demo` public and in CI smoke; share links revocable and leak nothing private; quick-log works on a phone; CI green; QA file written.

# Instagram ad strategy — US$50 validation test
**Not launched.** No ad account access was used; nothing here has run.

## Purpose
Learn, for $50: which hook earns the cheapest **sign-up**, and whether sign-ups go on to log trades. $50 cannot prove profitability; it can rule out a weak message.

## Preconditions (don't spend before these)
Live domain · email verification on · landing page loads fast on mobile · `?src=` tags working (built) · Meta pixel or conversions tracking decided (see tracking plan) · Privacy Policy updated if a pixel is added.

## Setup
| Item | Choice | Why |
|---|---|---|
| Objective | **Traffic → Landing page views** days 1–2; switch to **Leads/Conversions (sign-up)** only if the pixel/event is live and firing | $10/day is too little for conversion optimisation to learn; landing-page views give clean signal |
| Budget | $10/day × 5 days, ad-set level | |
| Placement | Instagram Reels + Stories only | Matches vertical creative |
| Audience | Ages 18–45; interests: Forex, Day trading, Technical analysis, TradingView, MetaTrader; English; countries: start with US + Jamaica + Trinidad & Tobago + UK (founder's market + large English markets) | Broad interest, let delivery find people |
| Creatives | 3 ads in one ad set (from videos 001, 004, 013) | Hook test: mistake vs psychology vs demo |
| Destination | `https://tradenotes.dev/?src=ig-ad-001` (and `-004`, `-013`) | Per-creative attribution stored at sign-up |
| CTA button | "Sign Up" | |

## Landing page recommendations
Keep the first screen to: one headline matching the ad ("Your win rate isn't the number that matters"), one sentence on what TradeNotes is, **Start free** button, a real app screenshot labelled sample data. Remove any unbuilt-feature mentions from above the fold. Load < 2 s on 4G.

## Compliance
Meta's financial-services ad policies: no income claims, no "get rich", no before/after money. Our copy is educational and makes no performance promises.

# Five-day optimisation plan ($10/day)
Decisions are rules set in advance so $50 isn't spent on gut feel. **No results exist yet** — fill in the tracking log, then apply these rules.

| Day | Action | Decision rule |
|---|---|---|
| 1 | Launch 3 ads, one ad set, $10 | Don't touch anything for 24 h (learning) |
| 2 | Review CTR and 3-second view rate per ad | If one ad has < half the CTR of the best after ≥1,000 impressions, pause it |
| 3 | Check sign-ups by `src` tag | If 0 sign-ups from ≥60 landing-page views, the landing page — not the ad — is the problem: shorten the first screen, match the headline to the best ad |
| 4 | Keep the best 1–2 ads | Do not add audiences mid-test (resets learning, muddies results) |
| 5 | Stop at $50. Pull final numbers | Write a one-page result: best hook, cost per click, cost per sign-up, activation rate |

## Benchmarks to judge against (rough, for small-budget consumer apps — treat as guesses)
CTR on Reels 0.5–1.5% · CPC $0.30–1.50 · landing-page → sign-up 10–30%. At $50 expect roughly 30–150 clicks and 3–30 sign-ups; **paid conversions within 5 days are unlikely and not the success criterion.**

## What to do with the result
- Cost per **activated** user < ~$10 and a clear winning hook → make 3 more variants of that hook; run a second $50–100 test.
- Clicks fine, sign-ups poor → fix landing page before spending more.
- Everything poor → put the budget back into organic content and retest in a month with the best-performing organic video as the ad.

# VO_008: What a 'lot' actually is
Written by: Claude Opus 5.5

## Narration
One lot of EURUSD is not one euro. One standard lot is a hundred thousand units of the base currency. For EURUSD, that's a hundred thousand euros of exposure. You only put up margin, but the exposure is real. On one lot, a twenty pip move is about two hundred dollars. A mini lot is zero point one, ten thousand units. A micro lot is zero point zero one, one thousand units. When you journal, write the size exactly. It changes your risk more than almost anything else. Follow for forex basics.

## Delivery notes
- Open straight on the hook with no warm-up breath. Stress "not" in "is not one euro".
- Steady teaching pace, a little under normal speech. Let each number land: "a hundred thousand", "twenty pip", "two hundred dollars".
- Short pause after "the exposure is real." It is the key idea before the maths.
- Read the three sizes as a list with the same rhythm each time: "zero point one, ten thousand", "zero point zero one, one thousand".
- Stress "exactly" in "write the size exactly". Friendly, plain tone, like explaining to a friend. No hype.

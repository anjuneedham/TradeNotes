## 5. Voiceover script
If you're new to forex, 'one lot' is confusing. One standard lot is a hundred thousand units of the base
currency. So one lot of EURUSD is a hundred thousand euros of exposure — with leverage, not your own money.
That's why a twenty-pip move is about two hundred dollars on one lot. A mini lot is point one — ten thousand
units. A micro lot is point oh one — a thousand units. Most beginners should start with micros. When you
journal, write the lot size exactly, because it changes your risk more than anything else.
